## Brand tokens derived from these files
Sampled straight from the pixels. Authoritative tokens live in
`docs/architecture/03-globals.css` + `03-tailwind-tokens.ts`.

- **Navy** `#0C2135` (deep `#06121D`) — sign-plate, primary text, admin canvas
- **Gold (marigold)** `#F0A818` (deep `#CE860C`, hi `#F7C24A`) — pin, stars, keyline, badges
- **Cream** page `#F5EDDA`, letters `#F2E7BE`
- **Barn red** `#B23A2E` — CTAs, "Call Now," alerts
- **No teal** — a muted pine `#2E7D5B` is used only for the "Open now" signal.

**Type:** Alfa Slab One (hero/stamps) · Oswald (headings/UI) · Public Sans (body).
**Motifs:** navy sign-plate + gold keyline · gold map-pin ("where") · stars · speed-lines.
**Icons:** Font Awesome **Free Solid** only (no Pro).
